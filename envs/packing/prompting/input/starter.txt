Examples of Valid Constraints:

    Example 1:
    Block the placelid action for lid1 on box1 if slab1 is not packed in box1.
    constraint = pd.make_not(predicate_packed.bind(["slab1", "box1"], problem))
    for obj, param in zip(["lid1", "box1"], action_placelid.parameters):
        blocked_assignment.assign(problem, param.name, obj)
    planner.block_expression_action(action_placelid, blocked_assignment, constraint, pd.Assignment())

    Example 2:
    Block the pack action for bb1 into box1 on top of box1 if bb2 is not packed in box1.
    constraint = pd.make_not(predicate_packed.bind(["bb2", "box1"], problem))
    for obj, param in zip(["bb1", "box1", "box1"], action_pack.parameters):
        blocked_assignment.assign(problem, param.name, obj)
    planner.block_expression_action(action_pack, blocked_assignment, constraint, pd.Assignment())

    Example 3:
    Block the pick action for slab2 from table if slab2 is packed in box1.
    constraint = predicate_packed.bind(["slab2", "box1"], problem)
    for obj, param in zip(["slab2", "table"], action_pick.parameters):
        blocked_assignment.assign(problem, param.name, obj)
    planner.block_expression_action(action_pick, blocked_assignment, constraint, pd.Assignment())
